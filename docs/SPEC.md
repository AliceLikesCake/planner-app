# Planner App — 完整規格（給 AI 開發助手）

這份文件是唯一的規格來源。開發時以這份為準；`design/mockups/` 裡的檔案是互動設計稿的原始碼，可以讀來確認版面、顏色、尺寸和互動，但它們依賴設計工具的執行環境，無法直接在瀏覽器打開。

---

## 1. 產品概要

- 一個人使用的生活管理 app：每日待辦、月曆行程、習慣打卡、接案（業配）管理、記帳。
- 亮點：完成待辦時會疊出當天的甜點（7 種，週一到週日各一種）；習慣用「戳泡泡」打卡；接案資料會自動同步到月曆、待辦和記帳。
- 平台：Vue 3 PWA，手機優先（設計尺寸 390 × 844），iPhone 用 Safari「加入主畫面」安裝。
- 語言：繁體中文（預設）與英文，**只在設定頁切換**，切換後整個 app 立刻變語言並記住。
- 風格：低飽和粉彩、米白底、**平面設計**。**只有蛋糕有立體感**（漸層、光影），其他元素都不要陰影或漸層。

## 2. 技術選型

| 項目 | 選用 |
| --- | --- |
| 框架 | Vue 3（`<script setup>`）+ TypeScript + Vite |
| 路由 | Vue Router |
| 狀態 | Pinia（每個模組一個 store） |
| 多語系 | vue-i18n（`src/locales/zh-TW.json`、`en.json`） |
| 後端 | Supabase：Auth（Google 登入）、Postgres、Row Level Security |
| PWA | vite-plugin-pwa，Web Push 推播（iOS 16.4+） |
| 音效 | Web Audio API，音檔在 `public/sounds/` |
| 匯出 | SheetJS（xlsx） |
| 測試 | Vitest（至少測 `services/sync.ts` 和蛋糕層數計算） |
| 部署 | Vercel |

規則：
- 不要引入 UI 元件庫（Element、Vuetify 等）；元件自己寫，依照第 3 節的設計規範。
- 只安裝必要且知名的套件，保留 `package-lock.json`。
- 環境變數：`VITE_SUPABASE_URL`、`VITE_SUPABASE_ANON_KEY`，放 `.env.local`，不可 commit。
- 畫面上所有文字都走 i18n，不可寫死在元件裡（使用者輸入的內容除外）。

## 4. 頁面規格

### 4.1 今日（`/`，Today）

版面由上到下：
1. 頂部：左邊日期（如「10月22日 星期四」，Huninn 23px）；右邊兩個 44px 圓形按鈕：音效開關、設定（齒輪，連到 `/settings`）。**沒有語言切換按鈕。**
2. 甜點卡（白卡，固定不捲動）：
   - 第一排：週一到週日 7 個按鈕（高 42、圓角 14、字 15px），今天預設選中（深色）。點別天可以預覽那天的甜點。
   - 第二排左：蛋糕區 148 × 150；右：甜點名稱、「完成 n / 總數 層」、進度條（`#E3A889`）、一句提示（「再完成 X 件，蛋糕就疊好了」／全部完成時「完成了！好好犒賞自己」）。
3. 「今日待辦」標題 + 右側「完成 n / 總數」。
4. 待辦清單：**獨立捲動區**，甜點卡固定在上面，所以無論捲到哪，打勾時都看得到蛋糕疊上去。
   - 每列：左 40 × 40 類別 icon 方塊（類別 fill 底 + text 色 icon）、中間標題 + 下方「時間 + 類別標籤」、右邊 28px 圓形勾選框（未完成：白底 + 類別色邊框）。
   - 完成後：勾選框變灰 `#A8A198` 底白勾、icon 方塊和類別標籤都變灰（`#E6E2DC` 底、`#8C857B` 字）、標題灰色加刪除線、整列底色 `#F3F0EB`。
   - 類別標籤顯示類別文字（工作、接案…），**不是口味名稱**。
   - 類別 icon：工作＝公事包、接案＝相機、學習＝書本、生活＝房子、健康＝愛心。

#### 蛋糕規則
- 每完成一件待辦，該類別顏色的一層從上方掉下來疊上（drop 動畫 520ms，`cubic-bezier(.2,.8,.3,1.2)`），勾選框彈一下。
- 還沒完成的層用虛線框顯示。
- **蛋糕層上不寫任何文字。**
- 層數計算（寫成純函式並測試）：
  - 待辦 ≤ 8 件：一件一層，每層高度 = clamp(總高 / 件數, 14, 30)。
  - 待辦 > 8 件：同類別合併成一層，高度 = 完成件數 × 單位高度（單位最小 7），剩下未完成的合成一塊虛線。
  - 設定裡的「一天最多疊幾層」（6/8/10/12）超過時也套用合併規則。
- 全部完成：頂部出現裝飾（依甜點不同：奶油、草莓、蠟燭、糖針、櫻桃…），蛋糕放大 1.08 再回 1.03，播放完成音效。
- 7 種甜點（週一到日，可在設定換）：草莓鮮奶油蛋糕、千層蛋糕、杯子蛋糕、冰淇淋聖代、焦糖布丁、鬆餅塔、三層派對蛋糕；另有提拉米蘇、草莓塔、生乳捲可選。
- 立體做法：每層是橢圓頂面（radial-gradient）+ 側面（左暗→亮→暗的 linear-gradient）+ 底部奶油夾心，放在有陰影的瓷盤上。詳細樣式見 `design/mockups/Main.dc.html` 的 `geom()`、`sideBg()`、`topBg()` 和 deco 區段。蛋糕整體縮放 0.56。
- 建議做成 `components/cake/Cake.vue`，props：`dessert`、`layers`（顏色 + 高度陣列）、`allDone`。

#### 音效（`services/sound.ts`）
- 疊一層：`/sounds/water-bubble.wav`，playbackRate = min(1.6, 0.9 + 0.06 × 第幾層)。
- 全部完成：最後一層的泡泡聲之後 0.18 秒播 `/sounds/fairy-glitter.wav`。
- 取消完成：合成的往下彈「咿啵」聲（sine 振盪器，頻率由 1.6f 降到 0.55f，加 LFO 抖動，0.3 秒）。
- 遵守設定的音效開關；第一次互動時才建立 AudioContext（iOS 限制）。

### 4.2 月曆（`/calendar`）

類似行事曆，一眼看到整個月的安排。
- 頂部：「2026年10月」+ 上個月、下個月按鈕。
- 類別篩選：全部、工作、接案、約會聚餐、旅行、學習、健康（可橫向捲動的膠囊）。
- 月曆格子：每格最小高 78，日期數字在上（今天：深色圓底白字；週末數字 `#A0605A`），下面最多 3 條行程標籤（高 16、字 10px、類別 fill 底），超過顯示「+N」。
- 跨天行程（如旅行）畫成橫跨多格的長條：起訖兩端圓角，跨週時下一排的第一格重新顯示文字。
- 點某一天，下方面板顯示：
  1. 當天行程：左邊類別色直條、標題、時間（跨天顯示「第 N 天」）、類別標籤。
  2. 當天待辦：標題右邊「完成 n / 總數」+ 進度條；**未完成的在前（彩色），已完成的在後（灰色、刪除線）**；過去日期沒完成的標示紅棕色「未完成」。
- 右下 ＋ → 新增行程。

### 4.3 習慣（`/habits`）

- 頂部：日期、「今天完成 n / 總數」、音效開關。
- 泡泡區（白卡）：每個習慣一顆泡泡（直徑 104–132，奇數顆往下錯開 22px），泡泡內寫習慣名稱和目標（如「喝水 2000 ml」），輕輕漂浮。
- **點一下就戳破**（每個習慣都一樣，沒有累加計數）：
  - 一圈外擴的圓環 + 8 顆水滴飛散（520ms），播放 water-bubble（rate 1.35）。
  - 戳破後留下虛線外框（縮到 0.72）+ 灰色勾 + 「連續 N 天」。
  - 再點一次復原。
  - 全部戳破：播放 fairy-glitter，顯示「今天的泡泡全部戳破了！」。
- **不顯示一週紀錄**。
- 最下面「10 月紀錄」：上方是每個習慣的切換膠囊（**沒有「全部」**），下面是該習慣的整月格子（圓形：做到＝習慣 fill 底 + deep 邊框；沒做到＝淺灰；未來＝虛線），今天加外圈。底部三個數字：本月完成天數、目前連續、最長連續。
- 習慣只在設定的星期幾出現。
- 右下 ＋ → 新增習慣。

### 4.4 接案（`/gigs`）

管理業配與接案。
- 頂部：「接案管理」。
- 三張統計卡：本月已入帳（綠）、待入帳（灰）、今年已入帳（薰衣草）。
- 篩選兩排：付款狀態（全部／待入帳／已入帳）；產品類別（全部類別、彩妝、保養、食品飲料、生活用品、3C 家電、服飾配件）。
- 卡片（未入帳的排前面）：
  - 上排：左邊 44 × 44 產品類別 icon 方塊；中間品牌名、「類別 · 合作形式」；右邊金額（稅前）+ 入帳狀態標籤（灰「待入帳」、綠「已入帳」、紅「逾期未入帳」）。
  - 中間一排 5 個勾選圈，照流程：**合約 → 勞報單 → 交稿 → 上線 → 入帳**。完成＝綠底白勾、粗體黑字；未完成＝空心圈、灰字；入帳逾期＝紅框紅字。點一下切換。點「入帳」會記錄今天為入帳日。
  - 底部一行小字：左「預計 10/25 上線」或「10/15 已上線」；右「預計 11/30 入帳」（逾期紅字）。
  - **沒有商品寄還欄位，沒有 8 段進度條，不用馬卡龍。**
- 產品類別 icon：彩妝＝口紅、保養＝瓶罐、食品飲料＝馬克杯、生活用品＝房子、3C 家電＝手機、服飾配件＝衣服。
- 右下 ＋ → 新增接案。

### 4.5 記帳（`/money`）

- 頂部：「記帳」+ 月份切換。
- 總覽卡：本月結餘（大字）、收入（綠）/ 支出（橘）、預算條（「預算 $25,000 · 已用 73%」「剩 $6,770」）。
- 分類卡：支出／收入切換；每個分類一列：38px icon 方塊、名稱、金額、橫條、百分比，由大到小排序。**不要用圓餅圖或甜甜圈。**
- 明細：依日期分組，每組標題是日期 + 當天合計；每筆：類別色點、名稱、下面只寫類別（**不顯示時間**）、金額（收入綠色）。
- 匯出 Excel 按鈕 → `/settings/export`。
- 右下 ＋ → 記一筆。
- 支出分類：餐飲、購物、生活、交通、娛樂、醫療、訂閱、其他。收入分類：薪資、接案、其他。

### 4.6 新增畫面

每個新增畫面最下面都有一塊「儲存後會同步到」的說明，依目前選項即時列出會同步到哪裡。

- **新增待辦**（`/add/task`）：名稱、類別（5 個）、類別選「接案」時可關聯某個接案、日期、時間（選填）、重複（不重複／每天／每週／每月）、提醒（前 30 分鐘）、顯示在月曆、備註。
- **新增行程**（`/add/event`）：名稱、類別（6 個）、整天開關、開始、結束（可跨天）、地點、提醒（不提醒／1 小時前／前一天／一週前）、同時加到今日待辦。
- **新增習慣**（`/add/habit`）：上方泡泡即時預覽、名稱、目標文字、泡泡顏色（7 色）、星期幾要做（7 個按鈕，顯示「每天」或「每週 N 天」）、每日提醒（21:30 未戳破時）。
- **新增接案**（`/add/gig`）：品牌、金額（稅前）、聯絡窗口、產品類別、合作形式（可複選：IG 貼文、IG Reels、限動、YouTube、部落格）、交稿日、上線日、預計入帳日、合約已簽、勞報單已簽、備註；「自動同步」區塊有 4 個可個別開關的項目（見第 6 節）。
- **記一筆**（`/add/money`）：頂部支出／收入切換、大字金額、分類圖示格（4 欄）、收入選「接案」時要選是哪個接案、日期、備註、底部數字鍵盤（1–9、00、0、⌫）。

### 4.7 設定（`/settings`）

- 帳號卡（→ 帳號與備份）。
- 一般：語言（中文／English）、一週從（週一／週日）、深色模式。
- 今日待辦與蛋糕：類別與顏色 →、沒做完的自動移到明天、每日蛋糕 →。
- 音效與通知：音效、推播通知、接案交稿提醒、入帳逾期提醒、習慣提醒時間。
- 自動同步：接案日期加到月曆、接案入帳自動記帳。
- 記帳：每月預算 →、記帳分類 →、匯出 Excel →。
- 資料：備份與同步 →、意見回饋。

子頁：
- **類別與顏色**（`/settings/categories`）：分頁「待辦類別／記帳分類」，點一列展開編輯名稱、9 色調色盤、預覽、刪除；底部「新增類別」。
- **每日蛋糕**（`/settings/cakes`）：週一到日各選一種甜點；每週隨機換、全部完成閃亮音效、完成的蛋糕收進月曆三個開關；一天最多疊幾層（6/8/10/12）。
- **每月預算**（`/settings/budget`）：總預算（±1000）、各分類預算（±500，顯示剩多少，80% 橘字、超支紅字）、快超支提醒、每月起算日（1 號／發薪日 5 號）。
- **匯出 Excel**（`/settings/export`）：時間範圍（本月／上個月／今年／自訂）、內容（記帳明細、接案收入含合約勞報單狀態、待辦完成紀錄、習慣紀錄）、格式（Excel／CSV）、檔名預覽、匯出按鈕。每個內容一個工作表。
- **帳號與備份**（`/settings/backup`）：同步狀態 + 立即同步、已同步裝置、每天自動備份、只在 Wi-Fi 同步、備份紀錄（還原要按兩次確認）、登出。

## 5. 資料模型

SQL 在 `supabase/schema.sql`（含 Row Level Security，每張表只能讀寫自己的資料）。

| 表 | 用途 |
| --- | --- |
| profiles / settings | 使用者設定（語言、音效、預算、甜點、同步開關…） |
| categories | 待辦、行程、記帳的類別，`name_zh` + `name_en`，顏色 key |
| tasks | 待辦，可帶 `gig_id`、`event_id`、`source` |
| events | 行程（可跨天），可帶 `gig_id`、`source` |
| habits / habit_logs | 習慣與每日紀錄 |
| gigs | 接案（品牌、金額、日期、合約、勞報單、交稿、上線、入帳） |
| transactions | 記帳，可帶 `gig_id` |

`source` 欄位：`manual`（使用者自己建）或 `gig` / `event`（自動產生）。自動產生的資料會跟著來源一起改、一起刪；使用者手動建的不受影響。

完成的蛋糕不另存，依當天 tasks 的完成狀態和設定即時算出。

## 6. 同步規則（全部寫在 `src/services/sync.ts`）

各頁面只呼叫 sync service，不要把同步邏輯散在元件裡。每條規則要能被設定開關控制，要冪等（重複執行不會重複產生資料）。

1. **接案 → 月曆**（設定：接案日期加到月曆）：建立或修改接案時，依交稿日、上線日、預計入帳日各 upsert 一個 event（`source='gig'`、`gig_id`、`kind` = deliver / live / due）。日期清空就刪掉該 event。
2. **接案 → 今日待辦**：交稿前一天產生「準備 {品牌} 交稿」、上線當天產生「確認 {品牌} 貼文上線」（類別＝接案，`source='gig'`）。
3. **接案文件 → 今日待辦**：合約或勞報單未簽時，明天產生「簽 {品牌} 合約／勞報單」；在接案頁勾選已簽時，該待辦自動完成。
4. **接案入帳 → 記帳**（設定：接案入帳自動記帳）：標記已入帳時新增一筆收入（分類＝接案、金額＝合作金額、`gig_id`）；改回待入帳時刪掉那筆。
5. **記帳 → 接案**：記一筆接案收入並選了接案時，該接案改成已入帳（入帳日＝那筆的日期）。
6. **今日待辦 → 月曆**：有日期的待辦會出現在月曆那天的待辦清單（直接查詢，不用複製資料）。
7. **月曆行程 → 今日待辦**：行程勾了「同時加到今日待辦」時，行程的每一天都產生一個待辦（`source='event'`）。
8. **習慣**：只存在習慣頁和每月紀錄，不進月曆。
9. **沒做完的移到明天**（設定開關）：每天第一次打開 app 時，把昨天以前未完成、非重複的待辦日期改成今天。

刪除接案時：刪掉 `source='gig'` 且 `gig_id` 相同的 events 和 tasks；對應的記帳收入詢問使用者要不要一起刪。

## 7. 多語系

- vue-i18n，`locale` 存在 settings；第一次開啟依 `navigator.language` 決定（zh 開頭用 zh-TW，其餘 en）。
- 起始語言檔在 `src/locales/`，key 依頁面分組（`nav.*`、`today.*`、`calendar.*`…），缺的 key 自行補齊，兩個檔案的 key 要一致。
- 日期、星期、金額用 `Intl.DateTimeFormat` / `Intl.NumberFormat` 依語言格式化。
- 類別用 `name_zh` / `name_en`；使用者自己輸入的文字不翻譯。
- 甜點名、推播通知、Excel 欄位名稱也要翻譯。
